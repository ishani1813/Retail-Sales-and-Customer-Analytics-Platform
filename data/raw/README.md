# Raw Data

`indian_store_data_SAMPLE.csv` in this folder is **synthetic placeholder data** (~4,000 rows),
generated by `generate_sample_data.py`, used only to build and test the cleaning notebook, SQL
schema, and Excel workbook end-to-end. It intentionally includes realistic messiness (mixed
date formats, a few missing values, some duplicate rows) so the cleaning step in the notebook
has real work to do.

**Before doing the real analysis or writing any business recommendation:**

1. Download the real dataset (~100K rows, 2019–2023, INR) from Kaggle:
   https://www.kaggle.com/datasets/abuhumzakhan/store-data
2. Save it as `indian_store_data.csv` in this folder.
3. In `notebooks/01_data_cleaning.ipynb`, change `RAW_PATH` to point at the real file.
4. Re-run the notebook, reload SQL, rebuild the Excel workbook and dashboard against the real
   numbers — the column names should match, but double-check against the Kaggle page and adjust
   `generate_sample_data.py`'s schema references if any column names differ slightly.

Findings, charts, and business recommendations should only be written up against the real
dataset — the synthetic sample is for pipeline-testing only and its "insights" aren't real.
